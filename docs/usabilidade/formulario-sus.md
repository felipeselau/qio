# Formulário SUS (System Usability Scale)

Aplicar após as tarefas, uma vez por participante, sobre o produto que ele usou (app para dono/operador, web para cliente). Referência original: Brooke, J. (1996), "SUS: a quick and dirty usability scale". ## Instruções ao participante

"Marque o quanto você concorda com cada frase, de 1 (discordo totalmente) a 5 (concordo totalmente), pensando no sistema que acabou de usar. Responda de forma espontânea; não há resposta certa."

## Cálculo do escore

1. Itens **ímpares** (1, 3, 5, 7, 9): contribuição = resposta − 1.
2. Itens **pares** (2, 4, 6, 8, 10): contribuição = 5 − resposta.
3. Some as 10 contribuições (0 a 40) e **multiplique por 2,5**. O escore vai de 0 a 100.
4. O escore do grupo é a média dos escores individuais. Não é um percentual.

Exemplo: respostas 4, 2, 5, 1, 4, 2, 5, 1, 4, 2 → ímpares: 3+4+3+4+3 = 17; pares: 3+4+3+4+3 = 17; soma 34 × 2,5 = **85**.
